# Изменения

## 0.6.1

- В «Статистике» появились лимиты подписки, время сброса, баланс кредитов и дополнительные окна из официальных CLI Codex и Claude Code.
- График и рейтинги учитывают локальные журналы, архивы и запуски ADE. Дополнительные CLI-профили доступны для просмотра расхода без изменения выбранного исполнителя.

## 0.6.0 · открытая альфа

- Изолированные аккаунты ChatGPT и Claude Code. Добавлены SIWC, выбор профиля по умолчанию и назначение аккаунтов по ролям.
- Дневной расход, покрытие измерениями, рейтинг профилей и сводка приёмки по проектам на этом Mac.
- Миграция SQLite до версии 6 сохраняет историю задач и запусков. Новые запуски записывают фактический профиль.
- Черновики сохраняются по задачам. На узких окнах навигация поддерживает клавиатуру и возврат фокуса.
