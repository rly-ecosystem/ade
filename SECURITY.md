# Сообщения о безопасности

Для уязвимости воспользуйтесь приватным сообщением о проблеме безопасности в [GitHub Security](https://github.com/rly-ecosystem/ade/security/advisories/new). Укажите версию ADE, операционную систему, затронутый сценарий и наблюдаемый результат на синтетических данных.

Токены, коды входа, рабочие базы, реальные пути и частные переписки оставьте на своём устройстве. Для пользовательских команд проверки выбирайте только доверенные проекты.
