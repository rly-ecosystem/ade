# Профили и статистика

## Аккаунты

Общий профиль использует уже выполненный вход соответствующего CLI. Для дополнительного ChatGPT-профиля нажмите **Continue with ChatGPT**. Системный браузер возвращает результат локальному приложению. Для Claude вход выполняет официальный CLI с отдельным каталогом настроек. Если браузер покажет одноразовый код, введите его в открывшемся поле ADE. После входа нажмите «Использовать аккаунт» либо укажите его в назначении роли.

Действующая цепочка сохраняет свои назначения. Имя фактического профиля отображается в переписке и истории запусков. После отключения выбранного профиля следующий запуск потребует явного выбора доступного аккаунта. При работе с изолированными профилями продолжение после лимита выбирает пользователь.

Профиль SIWC использует план ChatGPT в рамках выданных разрешений. ADE проверяет подпись и идентичность, обновляет близкий к истечению сеанс перед запуском и ограничивает время процесса сроком действия токена. Для продолжения прерванной работы можно начать следующий запуск в той же задаче. Лимиты и credits задаёт владелец в ChatGPT. [Настройки использования](https://chatgpt.com/settings/usage)

## Данные на Mac

Рабочая база SQLite и каталоги профилей находятся в `~/Library/Application Support/RLY ADE/`. Вход SIWC сохраняется в файле с правами 0600 внутри закрытого каталога профиля. Claude сам управляет своей авторизацией. Процессы с правами того же пользователя ОС составляют одну границу доверия. Для резервной копии закройте ADE и используйте защищённое хранилище.

Исполнитель получает контекст выбранной задачи и обрабатывает его через своего провайдера. Команда пользовательской проверки выполняется от имени пользователя Mac в доверенной папке. Внешняя продуктовая телеметрия выключена. Журналы, база и каталоги аккаунтов могут содержать приватный материал.

## Как читать статистику

Период включает сегодняшний день и определяется местным временем начала запуска. Сумма равна входным плюс выходным токенам по последнему отчёту каждого запуска. Повторные обновления одного запуска заменяют прежний отчёт. Чтение и запись кеша входят во входные токены. «В том числе из кеша» показывает только чтение.

Покрытие указывает число запусков с замером. При неполном покрытии известный расход — нижняя граница. Прочерк означает отсутствие замера, ноль показывает полученный нулевой отчёт. Эти данные описывают работу в ADE. Размер подписочной квоты и цену по ним определить нельзя.

Рейтинг сравнивает локальные профили по известным токенам либо числу завершённых запусков. Старые запуски до появления профилей относятся к общему CLI соответствующего провайдера. Стрелки, Home и End перемещают выбранный день графика. Под ним доступна таблица с точными значениями.

«До приёмки» считает уникальные задачи с запуском за период, в том числе архивированные. Вторая ступень требует завершившегося шага этой когорты. Последняя учитывает текущую сохранённую приёмку этого шага в том же периоде по последней сверке с файлами. Ручная приёмка тоже учитывается.
