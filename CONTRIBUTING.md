# Как внести изменение

Проверьте поведение по шагам из README. В pull request опишите пользовательский сценарий, изменённое поведение и команды проверки. Для изменений интерфейса приложите кадры с тестовыми данными в обеих темах.

Запустите `npm run typecheck` и `npm test`. После изменения интерфейса выполните `npm run build` и `npm run test:gui` на macOS. Для воспроизведения используйте временный проект и fixture CLI из tests. Запуск live-проверок расходует квоту владельца аккаунта.

В публичные отчёты включайте минимальные синтетические примеры. Сообщения о безопасности принимаются по инструкции в SECURITY.md.
