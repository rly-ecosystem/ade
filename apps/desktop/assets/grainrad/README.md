# ASCII koi

2026-11-16. Original top-view artwork: `koi-source.svg` → local PNG → https://grainrad.com, ASCII / STANDARD / default adjustments / Text export.

`koi-ascii.txt` is the actual Grainrad export. `../koi.js` samples its glyphs in pairs for a readable small sprite, retaining Grainrad's contour and density. Local animation bends the body and fins and responds to feeding. No remote renderer or asset requests at runtime. The original design-app scene is preserved separately.
